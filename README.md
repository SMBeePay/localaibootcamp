# Local AI Bootcamp

Static marketing site for localaibootcamp.com — in-person AI training for DFW teams.

- Plain HTML/CSS/JS, no build step needed to deploy. Hosted on GitHub Pages from the repo root (main branch). The CNAME file sets the custom domain.
- Pages are generated by `tools/build.py`. Edit copy there, then run `python3 tools/build.py .` from the repo root.
- Styles: `assets/style.css`. Form handling + mobile menu: `assets/site.js`.
- Forms post to Formspree. Replace `YOUR_FORM_ID` in `tools/build.py` and rebuild.
